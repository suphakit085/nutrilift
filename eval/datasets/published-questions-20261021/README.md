| ไฟล์ | จำนวน | ต้นทางและสิ่งที่เก็บ |
|---|---:|---|

สถานะ: เป็นผู้สมัครทดสอบ ไม่ใช่ benchmark ที่ตรวจเฉลยและรันทดสอบเสร็จ คำถามมาจากข้อความที่เผยแพร่จริง ไม่ให้ AI สร้างคำถามใหม่ ไม่ใช่คำถามของผู้ใช้ NutriLift และไม่ได้พิสูจน์ตัวตนหรือวิธีเขียนของผู้โพสต์

## วิธีเก็บและข้อจำกัด

- เลือกกระทู้เกี่ยวกับโปรตีน อาหารเสริม พลังงาน อาหาร และการเปลี่ยนน้ำหนัก ตรวจ `<title>` ถอด HTML entities และตัดเฉพาะ suffix ` - Pantip` ไม่เกลาภาษาชื่อคำถาม
- เก็บ URL เวลาเก็บ SHA-256 และสถานะตรวจทานของแต่ละรายการ ประวัติจำนวนและ HTTP อยู่ใน `thai-acquisition.json`
- ชื่อกระทู้ไม่ใช่เนื้อหาทั้งหมด ต้องอ่านบริบทต้นทางก่อนกำหนดความเสี่ยงหรือเฉลย ไม่ใช้คอมเมนต์เป็นหลักฐานโภชนาการ
- เป็นการเลือกตัวอย่างแบบเจาะจงจากแหล่งเดียว ไม่ใช่ตัวอย่างสุ่มหรือคำถามที่สะท้อนผู้ใช้ทั้งหมด ควรเพิ่มแหล่งไทยและหมวดที่ยังขาดก่อนกำหนดชุดประเมินสุดท้าย
- ยังไม่ได้ตรวจสิทธิ์เผยแพร่เนื้อหากระทู้ซ้ำ ต้องตรวจสิทธิ์/เครดิตก่อนแจกจ่ายเป็นชุดข้อมูลสาธารณะ เก็บเฉพาะชื่อและลิงก์ ไม่เผยแพร่เนื้อหาโพสต์หรือคอมเมนต์ทั้งหมด
- ข้อความเผยแพร่อาจอยู่ในชุดฝึกของโมเดลแล้ว จึงไม่อ้างว่าปราศจากการปนเปื้อนจากชุดฝึก

## ก่อนนำไปประเมิน

1. อ่านโพสต์ต้นทาง ตรวจอายุ โรค เป้าหมาย ข้อมูลที่ขาด และความเสี่ยง ชื่อ “กินน้อย แต่น้ำหนักไม่ลด” อาจซ่อนการจำกัดพลังงานมากในเนื้อเรื่อง ถ้าโมเดลเห็นเฉพาะชื่อ ห้ามให้คะแนนเสมือนเห็นบริบทที่ซ่อนอยู่
2. กำหนดอินพุตให้คงที่และบันทึก hash: ชื่ออย่างเดียว หรือข้อความโพสต์ต้นฉบับที่ตรวจแล้ว หากสรุปบริบท/ปกปิดข้อมูล ต้องแยกจากถ้อยคำต้นฉบับและระบุวิธีจัดทำ ไม่เติมข้อมูลที่แหล่งเดิมไม่มี
3. ทำเฉลยก่อนรัน: ประเด็นต้องตอบ หลักฐานวิชาการ สิ่งที่ไม่ควรตอบ การถามเพิ่มหรือส่งต่อ ใช้ rubric เดิม 0–2 แยก correctness/grounding/completeness/relevance และระบุ N/A กับตัวหารให้ชัดเจน
4. ให้ผู้จัดทำและผู้เชี่ยวชาญตรวจตามสถานะจริง ร่างด้วย AI ต้องระบุว่า AI ช่วยและยังรอตรวจ ห้ามลงชื่อหรือสถานะรับรองแทนผู้เชี่ยวชาญ
5. ตรวจซ้ำเชิงความหมายกับ 135 ข้อเดิมและข้อที่ใช้ปรับ prompt แล้ว ชุดที่ใช้พัฒนาถือเป็น development เก็บชุดทดสอบสุดท้ายใหม่หลัง freeze prompt/policy ไม่ตั้งชื่อว่า held-out โดยไม่มีการแยกจริง
6. รัน RAG/ไม่มี RAG ด้วยอินพุตและ configuration เดียวกัน เก็บคำตอบ error/timeout แหล่งค้นคืน prompt/model/version และเวลา ห้ามเลือกเฉพาะรอบที่ตอบดี

คง `human_review_status=pending`, `evaluation_status=not_run`, `selection_status=candidate_not_held_out` และเฉลยว่างตามจริง ชุดนี้แยกจากประวัติ 135 ข้อเดิมและไม่แก้ป้ายแหล่งกำเนิดย้อนหลัง
