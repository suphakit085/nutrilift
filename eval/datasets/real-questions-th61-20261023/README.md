# คำถามจริงภาษาไทย 61 ข้อ สำหรับทดสอบคุณภาพคำตอบ (prompt testing)

ชุดนี้ใช้ทดสอบคุณภาพคำตอบของแชตด้วยคำถามที่คนโพสต์จริงบนเว็บสาธารณะ ตามข้อเสนอแนะของอาจารย์ที่ปรึกษาว่าไม่ควรใช้คำถามที่ให้ AI แต่ง

| แหล่ง | จำนวน | สิ่งที่เก็บ |
|---|---:|---|
| Pantip | 50 | ชื่อกระทู้ต้นฉบับ (ตรวจกับ `<title>` ของหน้าเว็บจริง) |
| คอมเมนต์ YouTube | 9 | ข้อความคอมเมนต์ จาก 2 คลิป (ช่อง FIT DESIGN PRIME และ ThaiTopFitness) |
| Dek-D (กระทู้) | 2 | ชื่อกระทู้ต้นฉบับ |

## หลักการเก็บ

- คัดลอกถ้อยคำตรงตามต้นฉบับ ไม่แปล ไม่เกลา ไม่แก้คำผิด และ**ไม่ได้ให้ AI แต่งคำถาม**
- แต่ละข้อมี URL ต้นทาง เวลาที่เก็บ และ SHA-256 ของคำถาม (`dataset.jsonl`, ตารางใน `SOURCES.md`)
- ไม่เก็บชื่อผู้โพสต์ ไม่นำเนื้อหาโพสต์ คอมเมนต์อื่น หรือคำตอบของผู้อื่นมาใช้
- ข้อความจากโพสต์และคอมเมนต์ใช้เป็นโจทย์ทดสอบเท่านั้น **ไม่ใช่หลักฐานทางโภชนาการ**
- ยังไม่ได้ตรวจสิทธิ์การเผยแพร่ซ้ำ ถ้าจะแจกจ่ายชุดข้อมูลสาธารณะต้องตรวจสิทธิ์และให้เครดิตก่อน
- เป็นการเลือกแบบเจาะจงตามหัวข้อของโครงการ ไม่ใช่ตัวอย่างสุ่มของผู้ใช้ทั้งหมด ข้อความสาธารณะอาจอยู่ในข้อมูลฝึกของโมเดลแล้ว

## ไฟล์

| ไฟล์ | เนื้อหา |
|---|---|
| `dataset.jsonl` | คำถาม 61 ข้อ พร้อมแพลตฟอร์ม URL เวลาที่เก็บ hash และสถานะการตรวจ |
| `SOURCES.md` | ตารางแหล่งที่มาของทุกข้อ |
| `expectations.json` | พฤติกรรมที่คาดหวังและสิ่งที่ห้ามตอบของแต่ละข้อ **ร่างโดย AI จากถ้อยคำคำถามเท่านั้น ล็อกไว้ก่อนรันผลแรก** ยังต้องให้ผู้จัดทำและผู้เชี่ยวชาญตรวจ |
| `core-subset.json` | กฎและผลการเลือก "ชุดแกนกลาง" 20 ข้อที่รันซ้ำ 3 รอบ (เลือกจากหมวดหมู่และถ้อยคำเท่านั้น ไม่ดูผลทดสอบ) |
| `condition.json` | เงื่อนไขรอบทดสอบสุดท้าย: โปรไฟล์ตัวอย่าง จำนวนรอบ และกติกาการให้ผลที่ล็อกไว้ก่อนรัน |

ผลการทดสอบและวิธีทดสอบอยู่ใน [`docs/prompt-testing-real-questions-2026-10-23.md`](../../../docs/prompt-testing-real-questions-2026-10-23.md)
และสรุปผลรายข้อของรอบหลัก (`4fca71e`) อยู่ใน [`eval/reports/real-questions-4fca71e/`](../../reports/real-questions-4fca71e/)

ชุดนี้แยกจากคำถามประเมินเดิม 150 ข้อใน `eval/questions.jsonl` ซึ่งจัดทำขึ้นระหว่างพัฒนา (ส่วนใหญ่ใช้ AI ช่วยร่างตามที่ผู้จัดทำแจ้ง) ไม่ได้เก็บจากแหล่งที่เผยแพร่จริง
