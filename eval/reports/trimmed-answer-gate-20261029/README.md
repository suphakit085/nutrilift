# คำตอบที่ถูกตัดจนไม่ตอบคำถาม: ตรวจก่อนแสดง (29 ต.ค. 2569)

ผลทั้งหมดเป็นผลตรวจเบื้องต้นโดย AI (Claude) ยังไม่ได้ตรวจโดยผู้จัดทำหรือผู้เชี่ยวชาญ

## ปัญหา

ถ้าคำตอบยังมีประโยคที่ยืนยันกับแหล่งข้อมูลไม่ได้หลังแก้ไปแล้ว 1 รอบ ระบบจะตัดประโยคนั้นออก แล้วแสดงส่วนที่เหลือ ถ้าตรวจซ้ำผ่านและยังมีเนื้อหาอย่างน้อยหนึ่งประโยค แต่ระบบไม่ได้ดูว่าส่วนที่เหลือยังตอบคำถามอยู่หรือไม่

ตัวอย่าง:
- **บนเว็บจริงวันที่ 29 ต.ค.:** "ต้องกินเวย์ไหม หรือกินไข่แทน" เหลือแค่บรรทัดเรื่องไข่ ส่วนที่บอกว่าไม่ต้องกินเวย์ถูกตัดทิ้ง
- **รอบ c0201c3:** คำตอบถูกตัด 12 จาก 101 ผล ผู้จัดทำตรวจว่าไม่ผ่านเพราะขาดประเด็นหลัก 4 ผล

## วิธีแก้

แก้เฉพาะตอนที่คำตอบถูกตัด คำตอบที่ไม่ถูกตัดทำงานเหมือนเดิม
1. **ถามโมเดลเพิ่มอีกครั้ง:** หลังคำตอบที่ตัดแล้วผ่านการตรวจซ้ำ ระบบจะเรียกโมเดลสั้นๆ อีก 1 ครั้ง (`answer_coverage`) ได้ค่า true/false ว่ายังตอบคำถามหลักอยู่หรือไม่
2. **ถ้าไม่ตอบแล้ว ให้แก้อีกรอบ:** ระบบไม่แสดงคำตอบที่ตัดแล้ว แต่ให้โมเดลแก้อีก 1 ครั้ง โดยต้องตอบคำถามหลักจากสิ่งที่แหล่งข้อมูลระบุ หรือบอกตรงๆ ว่าแหล่งข้อมูลไม่ครอบคลุม
3. **ถ้าแก้แล้วยังไม่ตอบ:** ไม่แสดงคำตอบ

## ผล

ทดสอบคำถามจริงที่เคยถูกตัด 11 ข้อ กับคำถามเวย์หรือไข่ 1 ข้อ ข้อละ 3 รอบ

| ตัวชี้วัด | main `9921154` | สาขาใหม่ |
|---|---:|---:|
| ตัดแล้วขาดประเด็นหลัก | 2/36 | **0/36** |
| ผ่านตามความคาดหวัง | 33/36 | 33/36 |
| error (ไม่นับโควตาผู้ให้บริการ) | 0 | 0 |
| เวลากลาง | 30.3 วินาที | 31.7 วินาที |

**ข้อสังเกต:**
- **TH19:** ระบบพบว่าคำตอบที่ตัดแล้วไม่ตอบคำถาม 1 ครั้ง (TH19) และให้โมเดลแก้แล้ว แต่คำตอบใหม่บอกว่าแหล่งข้อมูลไม่ครอบคลุมสาเหตุ จึงยังไม่ผ่าน จำนวนข้อที่ผ่านในตัวอย่างนี้จึงไม่เปลี่ยน
- **TH20:** ไม่ผ่าน 2 ผลบนสาขาใหม่ ทั้งสองผลไม่ได้ถูกตัด เป็นปัญหาเดิมที่โมเดลตอบว่าแหล่งข้อมูลไม่พอ (ข้อจำกัดข้อ 13)
- **บริการขัดข้อง:** ฝั่งสาขาใหม่เจอโควตาผู้ให้บริการหมด ผลเหล่านี้เก็บไว้ใน `branch-service-fail/` แล้วรันใหม่ทั้งหมด
