# คลังความรู้ชุดที่ 2: การ์ด 8 ใบในหัวข้อที่คนเล่นเวทถามบ่อย (28 ต.ค. 2569)

ผลทั้งหมดเป็นผลตรวจเบื้องต้นโดย AI (Claude) ยังไม่ได้ตรวจโดยผู้จัดทำหรือผู้เชี่ยวชาญ การ์ดทุกใบมีสถานะ `ai_reviewed_pending_independent_review`

## การ์ด

| การ์ด | หัวข้อ |
|---|---|
| `pre-workout-meal` | มื้ออาหารก่อนเล่นเวท |
| `diet-breaks-refeeds` | diet break, refeed และ cheat meal |
| `alcohol-training` | แอลกอฮอล์กับการเล่นเวทและการลดไขมัน |
| `sleep-body-composition` | การนอนกับไขมันและมวลกล้ามเนื้อ |
| `dietary-fat` | ไขมันในอาหาร และไขมันอิ่มตัว |
| `sugar-sweeteners` | น้ำตาลและสารให้ความหวานแทนน้ำตาล |
| `meal-frequency` | จำนวนมื้อต่อวันและการกินมื้อดึก |
| `protein-quality` | คุณภาพโปรตีน, PDCAAS และ DIAAS |

- **แหล่งอ้างอิง:** อยู่ใน `knowledge/SOURCES.md` หัวข้อ 3e
- **หัวข้อที่ตัดออกจากแผน:** อัตราลดหรือเพิ่มน้ำหนัก (lean bulk กับ dirty bulk) และความเชื่อผิดเรื่องคาร์บ เพราะการ์ดที่ใช้อยู่ครอบคลุมแล้ว

## วิธีทดสอบ

**เหมือนชุดที่ 1:**
- เกณฑ์และคำถามทดสอบใหม่ 16 ข้อล็อกไว้ใน [`CRITERIA.md`](CRITERIA.md) ก่อนเขียนการ์ด
- การแก้ไขระหว่างทางบันทึกใน [`RUNLOG.md`](RUNLOG.md) ก่อนรันซ้ำทุกครั้ง
- การค้นคืนใช้ตัวจำลองในหน่วยความจำ ([`scripts/sim.py`](scripts/sim.py))

**ค่าฐาน:**
- เว็บจริงที่ใช้การ์ด 37 ใบ
- ตรวจแล้วว่าตัวจำลองให้ผลค้นคืนตรงกับผลสุดท้ายของชุดที่ 1 ครบ 61 ข้อ คะแนนต่างกัน 0

**ความต่างจากชุดที่ 1:** หัวข้อชุดนี้ไม่ได้เลือกจากคำถามจริงที่ตอบไม่ได้ คำถามจริงจึงใช้วัดเฉพาะว่าคำตอบเดิมแย่ลงหรือไม่ ส่วนความครอบคลุมวัดด้วยคำถามทดสอบใหม่ ซึ่ง AI เป็นผู้เขียน จึงเป็นตัวชี้วัดรอง

## ผลลัพธ์ (รอบที่ 3)

| ตัวชี้วัด | เว็บจริง (37 การ์ด) | การ์ด 45 ใบ |
|---|---:|---:|
| คำถามจริง: 75 ผลที่ผลค้นคืนเปลี่ยน | 65 ผ่าน | **67 ผ่าน** |
| คำถามทดสอบใหม่ (16 ข้อ) | 4 ผ่าน | **16 ผ่าน** |
| คำตอบนโยบายการแพทย์ (5 ผล) | ผ่านตามนโยบาย | เหมือนเดิม |
| ข้อมูลผิดใหม่ | – | 0 |
| C1: คำถามนอกเรื่องที่ผ่านเกณฑ์ค้นคืน (15 ข้อ) | 2 | 2 |
| C2: คำถามประเมินที่ค้นเจอการ์ดตามป้ายเดิม (125 ข้อ) | 112 | 109 (ผ่านหลังเปลี่ยนป้ายเฉลย ไม่มีข้อที่ถูกเบียดจริง) |

**รายละเอียดคำถามจริง**
- **จากไม่ผ่านเป็นผ่าน 5 ผล:** TH02-r2, TH14-r2, TH19-r1, TH20-r3, TH27-r1
- **จากผ่านเป็นไม่ผ่าน 3 ผล:**
  - TH02-r3 และ TH05-r3: ผลค้นคืนไม่มีการ์ดชุดที่ 2 เลย จึงเป็นความผันผวนของโมเดล
  - TH26-r3: ถูกปัดตกทั้งคำตอบเพราะติดป้ายอ้างอิงผิด เนื้อหาที่อ้างไม่ได้มาจากการ์ดชุดที่ 2
- **C2:** มี 3 ข้อที่ค้นไม่เจอการ์ดตามป้ายเดิม คือ Q080, Q087 และ Q139 ทั้งสามไปเจอการ์ดที่ครอบคลุมคำถามแทน และบันทึกการเปลี่ยนป้ายเฉลยไว้ก่อนเห็นคำตอบ

## ทำไมต้องรัน 3 รอบ

- **รอบที่ 1:** ไม่ผ่าน A1 (61 เทียบกับ 65)
  - คำถามแนว "คุมอาหารแล้วน้ำหนักไม่ลด" (TH15, TH19, TH20, TH25) ไปดึงการ์ด diet break, จำนวนมื้อ และการนอนมาการ์ดละ 2 ชิ้น
  - การ์ดเหล่านี้เบียดการ์ดการปรับตัวของระบบเผาผลาญและสมดุลพลังงานออกไป คำตอบจึงไม่อธิบายสาเหตุที่น้ำหนักไม่ลด
  - **แก้:** ย่อการ์ด 4 ใบให้เหลือหัวข้อเดียว
- **รอบที่ 2:** ยังไม่ผ่าน A1 (63 เทียบกับ 65)
  - การ์ด diet break ยังเบียดการ์ดการปรับตัวในคำถาม TH20
  - ถ้าวัดความคล้ายด้านความหมายอย่างเดียว การ์ดนี้อยู่อันดับ 12 แต่ขั้นจับคำตรง (BM25) ดันขึ้นมา เพราะในการ์ดมีคำว่า "คุมอาหาร" และ "ลดน้ำหนัก" ตรงกับคำถาม
  - **แก้:** เปลี่ยนสำนวนในการ์ดให้ไม่ใช้สองคำนี้ ตัวเลขไม่เปลี่ยน
- **รอบที่ 3:** ผ่านทุกเกณฑ์

**บทเรียนสำหรับชุดถัดไป:** การ์ดใหม่ควรมีหัวข้อน้อย และหลีกเลี่ยงคำที่เป็นคำหลักของคำถามในหัวข้ออื่น เพราะการจับคำตรงในการค้นคืนจะดึงการ์ดนั้นเข้าไปเบียดได้

## ข้อสังเกต

- **การ์ดแอลกอฮอล์:** ติดท้ายผลค้นคืนของคำถามโปรตีนบางข้อในรอบแรก แต่คำตอบไม่ได้ใช้เนื้อหานั้น
- **TH17-r1:** เรียกระดับ DIAAS ตั้งแต่ 75 ขึ้นไปว่า "PDCAAS" ผิดเล็กน้อย
- **K07:** อธิบายมวลไร้ไขมันว่าเป็น "มวลกล้ามเนื้อและน้ำ" ซึ่งเป็นการอธิบายเพิ่มที่ไม่มีในการ์ด
