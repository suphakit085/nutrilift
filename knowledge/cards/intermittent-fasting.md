# IF กับการลดไขมันและรักษากล้ามเนื้อ

IF มีหลายรูปแบบ การจำกัดช่วงเวลากินไม่เหมือนการสลับวันจำกัดพลังงาน ISSN ปี 2017 รายงานว่าผล time-restricted feeding ร่วมการฝึกแรงต้านยังผสมกัน ขณะที่งาน intermittent caloric restriction โดยรวมไม่ได้แสดงข้อได้เปรียบชัดเหนือการจำกัดพลังงานทุกวันต่อองค์ประกอบร่างกาย ข้อสรุปนี้มีขอบเขตตามวรรณกรรมปี 2017

การลดไขมันอาศัยขาดดุลพลังงานต่อเนื่อง ส่วนการรักษามวลไร้ไขมันควรพิจารณาโปรตีนเพียงพอ การฝึกแรงต้าน และอัตราลดน้ำหนัก ไม่ถือว่าการอดอาหารเองรับประกันผลดีกว่าหรือป้องกันการเสียกล้ามเนื้อ

การประยุกต์ของโครงการ: หากเลือก IF ให้จัดพลังงานและโปรตีนรวมในช่วงกินที่ทำได้จริง จำนวน 3 มื้อหรือช่วง 8 ชั่วโมงเป็นเพียงตัวอย่างจัดตาราง ไม่ใช่เกณฑ์ขั้นต่ำจากงานวิจัยหรือใบรับรองว่าจะเพิ่มกล้ามเนื้อได้เท่าตารางอื่น

ขอบเขตของโครงการ: ข้อมูลสรุปนี้ไม่กำหนดการอดอาหารเพื่อรักษาโรค ผู้ใช้ที่มีโรคประจำตัว ใช้ยา หรือต้องจัดอาหารเฉพาะควรให้ผู้รักษาช่วยวางแผนรายบุคคล
