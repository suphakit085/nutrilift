# IF ดีกว่าการคุมแคลอรี่แบบปกติไหม

**ไม่ดีกว่า** จุดยืนของ ISSN เรื่อง diets and body composition (Aragon และคณะ 2017)
ระบุไว้ตรง ๆ ว่า งานวิจัยเรื่องการจำกัดพลังงานเป็นช่วง (intermittent caloric restriction)
โดยรวมแล้ว **ไม่แสดงข้อได้เปรียบที่มีนัยสำคัญเหนือการจำกัดพลังงานแบบรายวัน**
ในการปรับปรุงองค์ประกอบร่างกาย

เอกสารเดียวกันยังสรุปว่า **รูปแบบอาหารที่หลากหลาย ตั้งแต่ไขมันต่ำไปจนถึงคาร์โบไฮเดรตต่ำ
หรือคีโตเจนิก และทุกจุดระหว่างนั้น ให้ผลต่อองค์ประกอบร่างกายได้ใกล้เคียงกัน**

สรุปคือ IF เป็น **เครื่องมือหนึ่งในการคุมพลังงาน** ไม่ใช่วิธีที่เหนือกว่าโดยตัวมันเอง
ถ้าการจำกัดเวลากินช่วยให้คุณกินน้อยลงและทำได้ต่อเนื่อง มันก็ได้ผลกับคุณ
ถ้าไม่ ก็ไม่จำเป็นต้องฝืนทำ

# ปัจจัยที่กำหนดว่าอาหารแบบไหนจะสำเร็จ

ISSN ระบุว่าความสำเร็จระยะยาวของการควบคุมอาหารขึ้นกับ **การทำได้ต่อเนื่อง (compliance)**
และการรับมือกับปัจจัยที่ขัดขวาง เช่น การปรับตัวของระบบเผาผลาญ

หลักการที่เอกสารสรุปไว้เรียงตามลำดับความสำคัญคือ
- การลดไขมันขับเคลื่อนด้วย **การขาดดุลพลังงานที่ต่อเนื่อง** คนที่มีไขมันสะสมมากกว่า
  สามารถใช้การขาดดุลที่มากกว่าได้ ส่วนคนที่ผอมอยู่แล้ว การลดช้ากว่าจะรักษามวลกล้ามเนื้อได้ดีกว่า
- การเพิ่มมวลกล้ามเนื้อขับเคลื่อนด้วย **การเกินดุลพลังงานที่ต่อเนื่อง** ร่วมกับการฝึกที่หนักขึ้น

# ข้อควรระวังเฉพาะสำหรับคนเล่นเวท

ประเด็นที่ IF อาจเป็นปัญหาไม่ใช่เรื่องพลังงาน แต่เป็นเรื่อง **การกระจายโปรตีน**

จุดยืน ISSN เรื่อง nutrient timing แนะนำให้กินโปรตีน 20-40 กรัมต่อมื้อ (0.25-0.40 g/kg/มื้อ)
ทุก 3-4 ชั่วโมง ซึ่งเป็นรูปแบบที่ให้ผลต่อการสังเคราะห์โปรตีนกล้ามเนื้อดีที่สุด

การบีบหน้าต่างการกินให้แคบมาก เช่น 4 ชั่วโมง ทำให้กระจายโปรตีนได้เพียง 1-2 มื้อ
และอาจทำให้โปรตีนรวมทั้งวันไม่ถึงเป้าเพราะกินไม่ทัน สำหรับคนเล่นเวท
**หน้าต่าง 8 ชั่วโมงขึ้นไปที่กระจายโปรตีนได้ 3 มื้อ ปฏิบัติได้จริงกว่า**

อีกประเด็นคือถ้าฝึกในช่วงที่อดอยู่ อาจต้องวางแผนมื้อรอบการฝึกให้ดี
ตามหลักที่ว่าขนาดและเวลาของมื้อก่อนฝึกมีผลต่อความจำเป็นของมื้อหลังฝึก

# สรุปสำหรับผู้ใช้

ถ้าชอบ IF และทำแล้วคุมอาหารได้ดีขึ้น ให้ทำต่อได้ โดยตรวจสองอย่าง
1. โปรตีนรวมทั้งวันถึงเป้าหรือไม่
2. กระจายโปรตีนได้อย่างน้อย 3 มื้อในหน้าต่างที่กินหรือไม่

ถ้าสองข้อนี้ผ่าน IF จะให้ผลไม่ต่างจากการคุมแคลอรี่แบบกระจายทั้งวัน
ถ้าไม่ผ่าน การขยายหน้าต่างการกินจะเป็นประโยชน์มากกว่าการฝืนอดต่อ

# ข้อควรระวัง

ผู้ที่มีภาวะน้ำตาลในเลือดผิดปกติ เบาหวาน กำลังตั้งครรภ์ ให้นมบุตร มีประวัติพฤติกรรม
การกินผิดปกติ หรืออายุต่ำกว่า 18 ปี ไม่ควรทำ IF โดยไม่ปรึกษาแพทย์
เพราะการอดอาหารเป็นช่วงอาจกระตุ้นรูปแบบการกินที่เป็นปัญหาได้
