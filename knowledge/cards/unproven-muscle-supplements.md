# ทำไมต้องรู้เรื่องนี้

อาหารเสริมกลุ่มนี้ขายดีในตลาดฟิตเนสและมักถูกโฆษณาว่าช่วยเพิ่มกล้ามเนื้อหรือความแข็งแรง แต่เมื่อ
รวบรวมงานวิจัยแบบสุ่มมีกลุ่มควบคุม (RCT) ในคนแล้ว **ส่วนใหญ่ไม่พบผลที่ต่างจากยาหลอกอย่างมี
นัยสำคัญ** การรู้ว่าตัวไหนไม่คุ้มเงินช่วยให้เอาเงินไปลงกับสิ่งที่ได้ผลจริงแทน เช่น โปรตีนให้พอ ครีเอทีน
และการฝึกที่มีคุณภาพ

# BCAA เดี่ยว ๆ (ไม่ใช่โปรตีนรวม)

BCAA (ลิวซีน ไอโซลิวซีน วาลีน) มีบทบาทกระตุ้นการสร้างกล้ามเนื้อจริงในระดับเซลล์ แต่เมื่อเทียบ BCAA
เดี่ยว ๆ กับเวย์โปรตีนที่มี BCAA ปริมาณเท่ากัน งานวิจัยพบว่าเวย์โปรตีนกระตุ้นการสังเคราะห์โปรตีน
กล้ามเนื้อได้**มากกว่า** เพราะกรดอะมิโนจำเป็นตัวอื่นก็จำเป็นต่อกระบวนการนี้ด้วย ไม่ใช่แค่ BCAA
สรุปคือถ้ากินโปรตีนคุณภาพดีพอต่อวันอยู่แล้ว (ดูการ์ด `protein-requirement`) ไม่มีความจำเป็นต้องซื้อ
BCAA เพิ่มอีก

# กลูตามีน (Glutamine)

ทฤษฎีดูดี (ช่วยเพิ่มปริมาตรเซลล์ ลดการสลายโปรตีน) แต่งานวิจัยในคนที่ฝึกแรงต้านส่วนใหญ่**ไม่พบผล
ต่อมวลกล้ามเนื้อหรือความแข็งแรง** แม้แต่ในขนาดสูง กลูตามีนอาจมีประโยชน์ด้านอื่น เช่น ช่วยลดอาการ
ปวดเมื่อยหลังฝึกหนักมากในบางงานวิจัย แต่ไม่ใช่สารสร้างกล้ามเนื้อ

# อาร์จินีน (Arginine)

ทฤษฎีคือเพิ่มไนตริกออกไซด์ (NO) ทำให้เลือดไหลเวียนดีขึ้นและส่งสารอาหารได้มากขึ้น แต่งานวิจัยส่วนใหญ่
**ไม่พบว่าอาร์จินีนเดี่ยว ๆ เพิ่มการไหลเวียนเลือดหรือการสังเคราะห์โปรตีนกล้ามเนื้อ**ได้จริงในทางปฏิบัติ
(สาเหตุหนึ่งคืออาร์จินีนที่กินเข้าไปถูกทำลายในลำไส้/ตับไปมากก่อนถึงกล้ามเนื้อ) ถ้าต้องการเพิ่ม NO จริง
ๆ สารที่มีหลักฐานเรื่องนี้ดีกว่าคือไนเตรตจากน้ำบีทรูท ซึ่งก็เป็นเรื่องของสมรรถภาพความอดทนมากกว่า
การสร้างกล้ามเนื้อ

# ดี-แอสพาร์ติกแอซิด (D-Aspartic Acid)

ขายในชื่อ "ตัวเพิ่มเทสโทสเตอโรนธรรมชาติ" แต่งานวิจัยแบบสุ่มมีกลุ่มควบคุมในผู้ชายที่ฝึกเวทพบว่า
**ไม่มีผลต่อระดับเทสโทสเตอโรน หรือความแข็งแรง/มวลกล้ามเนื้อ**เลย ทั้งขนาด 3 กรัมและ 6 กรัมต่อวัน

# ZMA (สังกะสี-แมกนีเซียม-แอสพาร์เตต)

ขายในชื่อช่วยเพิ่มเทสโทสเตอโรนและ IGF-1 ผลการวิจัยขัดแย้งกันเอง งานที่เคยรายงานผลบวกพบว่ากลุ่ม
ทดลองมีภาวะขาดสังกะสี/แมกนีเซียมมาก่อน ซึ่งอธิบายได้ว่าผลบวกมาจากการแก้ไขภาวะขาดสารอาหาร
ไม่ใช่ฤทธิ์ทางเภสัชวิทยาของ ZMA เอง **ในคนที่ไม่ได้ขาดสังกะสีหรือแมกนีเซียมอยู่แล้ว ไม่มีหลักฐานว่า
ZMA เพิ่มเทสโทสเตอโรน ความแข็งแรง หรือมวลกล้ามเนื้อ**

# ทริบูลัส เทอเรสทริส (Tribulus terrestris)

สมุนไพรที่อ้างว่ากระตุ้นการหลั่งฮอร์โมนที่นำไปสู่การสร้างเทสโทสเตอโรน แต่งานวิจัยในคนพบว่า
**ไม่มีผลต่อองค์ประกอบร่างกายหรือความแข็งแรง**ระหว่างการฝึกแรงต้าน ทั้งใช้เดี่ยวหรือผสมกับสารอื่น

# โปรฮอร์โมนและสารตั้งต้นแอนโดรเจน

สารเช่น androstenedione, DHEA และสารตั้งต้นอื่น ๆ ที่อ้างว่าเปลี่ยนเป็นเทสโทสเตอโรนในร่างกาย
งานวิจัยในผู้ชายวัยหนุ่มที่มีฮอร์โมนปกติพบว่า**ส่วนใหญ่ไม่เพิ่มเทสโทสเตอโรนจริง** และบางตัวกลับเพิ่ม
เอสโตรเจนและลด HDL คอเลสเตอรอล (ไขมันดี) สารกลุ่มนี้จัดเป็น "สารคล้ายสเตียรอยด์" องค์กรกีฬา
ส่วนใหญ่ห้ามใช้ และการกินผลิตภัณฑ์ที่มีสารกลุ่มนี้ปนเปื้อน (แม้ไม่ได้ตั้งใจ) อาจทำให้ตรวจสารต้องห้าม
เป็นผลบวกได้

# ข้อควรระวัง

รายชื่อนี้อิงจากงานวิจัยที่มีอยู่ ณ ปีที่ตีพิมพ์แหล่งอ้างอิง หลักฐานใหม่อาจเปลี่ยนได้ในอนาคต และการ
"ไม่มีหลักฐานว่าได้ผล" ไม่เท่ากับ "เป็นอันตราย" เสมอไป — บางตัวปลอดภัยแต่แค่ไม่คุ้มเงิน ส่วนสารกลุ่ม
โปรฮอร์โมน/แอนโดรเจนมีความเสี่ยงด้านสุขภาพและกฎการแข่งขันที่ต้องระมัดระวังเป็นพิเศษ
