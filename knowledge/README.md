# ฐานความรู้ (knowledge base)

## โครงสร้าง

```
knowledge/
├─ cards/          knowledge cards ภาษาไทย 1 ไฟล์ = 1 หัวข้อ (ต้นทางของ RAG)
│  └─ _TEMPLATE.md ไฟล์ที่ขึ้นต้นด้วย "_" จะไม่ถูก ingest
├─ sources/        PDF/เอกสารต้นฉบับ (ไม่ commit ขึ้น git)
├─ SOURCES.md      บรรณานุกรมกลาง + เช็กลิสต์ว่าอ่าน/สรุปอะไรไปแล้ว
└─ foods.csv       ตารางคุณค่าทางโภชนาการอาหารไทย (ต้นทางของ lookup_food)
```

## foods.csv — สถานะข้อมูล

**339 แถว: ข้อมูลจริง 321 แถว · ยังเป็นค่าชั่วคราว 18 แถว**

| ที่มา (`source`) | จำนวน | ความหมาย |
|---|---|---|
| `ASEAN-FCD-2014-INMU:<id>` | 314 | ค่าจริงจาก ASEAN Food Composition Database (ส่วนใหญ่ต่อ 100 กรัม) พร้อมรหัสอาหารให้ตรวจย้อนได้ |
| `DOH-NSS-2018:<id>` | 9 | ค่าจริงจาก **ตารางคุณค่าทางโภชนาการของอาหารไทย** (Nutrition Surveillance System, กองโภชนาการ กรมอนามัย, ก.ย. 2561) — ไฟล์สแกน 148 หน้า ไม่มี text layer อ่านด้วยการแปลงภาพเป็นข้อความทีละหน้า พร้อมรหัส Food ID ให้ตรวจย้อนได้ |
| `TOVERIFY-INMU` | 16 | **ยังเป็นค่าประมาณ** ส่วนใหญ่เป็นเมนูที่ตรวจสอบแล้วว่า**ไม่มีในทั้งสองแหล่ง** (ASEAN และ DOH-NSS) จริง ไม่ใช่แค่ยังไม่ได้หา — ดูรายละเอียดด้านล่าง |
| `TOVERIFY-LABEL` | 2 | เวย์โปรตีน, ชานมไข่มุก — เป็นผลิตภัณฑ์ยี่ห้อ/เครื่องดื่มผสม ไม่มีในฐานข้อมูลองค์ประกอบอาหารตามธรรมชาติ ต้องอ้างฉลากสินค้าจริงเป็นราย ๆ ไป (สถานะนี้ถูกต้องแล้ว ไม่ใช่ของที่ต้องแก้)

สร้างใหม่ได้ด้วย
```bash
curl -sL -o knowledge/sources/ASEAN-FCD-v1-2014.pdf     https://inmu.mahidol.ac.th/aseanfoods/doc/OnlineASEAN_FCD_V1_2014.pdf
python tools/extract_asean_fcd.py    # PDF -> asean_thai_foods.csv
python tools/build_foods_csv.py      # -> knowledge/foods.csv
```

**การควบคุมคุณภาพของตัวแยกข้อมูล** ทุกแถวต้องผ่านด่านตรวจว่า *พลังงานตรงกับสารอาหารของตัวเอง*
(4 kcal/g สำหรับโปรตีนและคาร์บ, 9 สำหรับไขมัน คลาดเคลื่อนได้ไม่เกิน 25%)
ซึ่งจับคอลัมน์ที่เลื่อนได้โดยไม่ต้องมีข้อมูลอ้างอิง — จาก 379 แถวที่มีค่าครบ ผ่าน 309 แถว
ที่เหลือถูกปฏิเสธเพราะ PDF แตกตัวเลขเป็นตัวอักษรเดี่ยวหรือคอลัมน์เลื่อนจนกู้ไม่ได้
**เลือกให้เหลือน้อยแต่ถูก ดีกว่ามากแต่มีค่ามั่วปน**

ตรวจสอบกับค่าที่ทราบอิสระแล้ว: อกไก่ดิบ 152 kcal / โปรตีน 19.9 g · ข้าวเจ้าสุก 129 kcal /
โปรตีน 2.2 g · ไข่ขาว 52 kcal / โปรตีน 10.9 g

**การจับคู่รายการเดี่ยวที่เหลือ (`tools/build_foods_csv.py` รอบที่ 2)** — 4 เมนูวัตถุดิบเดี่ยว
ที่เคยเป็นค่าประมาณ (ข้าวสวย, หมูสันใน, ไข่ขาวต้ม, มะละกอสุก) แทนที่ด้วยค่าจริงจาก ASEAN แล้ว
โดยตรวจชื่ออังกฤษคู่กับชื่อไทยเสมอก่อนจับคู่ — วิธีนี้จับได้ว่า "กล้วยน้ำว้า" ที่ดูตรงชื่อ
แท้จริงคือรายการ *"Banana, apple variety"* (กล้วยไข่) คนละพันธุ์ จึง**ไม่ใช้**
ส่วน "สะโพกไก่ไม่มีหนัง" พบใน ASEAN แต่ระบุชัดว่า *"w/ skin"* (มีหนัง) จึงไม่ใช่ของเดียวกัน ไม่ใช้เช่นกัน
ทั้งสองกรณีนี้ถ้าใช้แบบไม่ตรวจชื่ออังกฤษ จะได้ตัวเลขที่ผิดแต่ดูน่าเชื่อถือ

**รอบที่ 3 (31 ส.ค. 2569) — DOH-NSS-2018 แก้ 9 แถว** ไฟล์ต้นฉบับ 86 MB เกินขนาดที่อ่านได้ครั้งเดียว
(20 MB) จึงตัดเป็น 15 ไฟล์ย่อยด้วย `pypdf` (คนละเครื่องมือกับที่ใช้แยกหน้า PDF ปกติ เพราะ `pdftoppm`
ไม่ได้ติดตั้งในเครื่องนี้) แล้วใช้สารบัญของเล่ม (มี offset หน้าพิมพ์ vs หน้า PDF ต่างกัน +2) นำทางไปยัง
หมวดที่ต้องการ ได้ของจริง 2 อย่าง:
- **วัตถุดิบเดี่ยว 2 รายการ** จาก ASEAN ที่พลาดไปตอนจับคู่อัตโนมัติ (ปลานิลต้ม — เปลี่ยนชื่อจาก
  "ปลานิลนึ่ง" เพราะค่าที่มีจริงคือต้ม ไม่ใช่นึ่ง; ไข่ไก่ต้ม — ใช้ค่าไข่ดิบแทนได้เพราะต้มไม่เปลี่ยนสารอาหาร
  เหมือนกรณีไข่ขาวต้มรอบก่อน)
- **เมนูปรุงสำเร็จ 7 รายการ** จาก DOH-NSS-2018 (ข้าวมันไก่, ข้าวกะเพราไก่ — ตัดคำว่า "ไข่ดาว" ออก
  เพราะค่าที่มีไม่รวมไข่, ส้มตำปู-กุ้ง — เปลี่ยนชื่อจาก "ส้มตำไทย" เพราะสูตรที่มีจริงใส่ปูกับกุ้งแห้ง,
  ลาบคั่วหมู — เปลี่ยนชื่อจาก "ลาบหมู" เพราะเป็นสูตรคั่ว, ไก่ทอดกระเทียมพริกไทย — เปลี่ยนชื่อจาก
  "ไก่ทอด" เพราะเป็นสูตรเฉพาะ, นมจืดพร่องมันเนย, โยเกิร์ตรสธรรมชาติ)

**ตรวจแล้วว่าไม่มีจริง ๆ ไม่ใช่แค่ยังไม่ได้หา** (เช็คทั้งสองแหล่งแล้ว): ปลาแซลมอน, เนื้อวัวไม่ติดมัน
(คัต), หมูสามชั้น, กุ้งต้ม (มีแต่กุ้งแห้ง/กุ้งดิบ), ไข่ดาว (การทอดเพิ่มไขมันจนใช้ค่าไข่ดิบแทนไม่ได้),
ผัดไทยกุ้งสด, ข้าวผัดกุ้ง, ต้มยำกุ้งน้ำใส (ไม่มีในสารบัญ DOH-NSS-2018 เล่มนี้เลย แม้จะเป็นเมนูที่คุ้นเคย
มาก), ผัดผักรวมและแกงเขียวหวานไก่แบบเดี่ยว ๆ (DOH-NSS-2018 มีแต่แบบรวมข้าวเป็นจานเดียว ซึ่งจะ
ทำให้แคลอรี่สูงเกินจริงถ้านำมาแทนแบบกับข้าวเปล่า ๆ), เต้าหู้ขาวแข็ง (หมวดถั่วเมล็ดแห้งของ
DOH-NSS-2018 มีแต่เต้าหู้อ่อน/ทอด/เหลือง/หมัก ไม่มีแข็งธรรมดา), ถั่วเหลืองต้ม (มีแต่ถั่วเหลืองดิบ/คั่ว
และ "ถั่วแระต้ม" ซึ่งคือถั่วเหลืองอ่อน/เขียว — คนละผลิตภัณฑ์กับถั่วเหลืองเมล็ดแก่ต้ม จึงไม่ใช้) —
ตรวจครบทุกหมวดที่เกี่ยวข้องในเอกสารนี้แล้ว (เนื้อสัตว์, ปลา, ไข่, นม, ถั่วเมล็ดแห้ง, อาหารปรุงสำเร็จ)

**ข้อจำกัดที่ต้องรู้**
- ค่าทั้งหมดเป็น **ต่อ 100 กรัม** ไม่ใช่ต่อจาน เมนูจานเดียวยังต้องหาแหล่งที่ให้ค่าต่อหน่วยเสิร์ฟ
- ชื่ออังกฤษบางแถวยังมีรหัสประเทศหรือชื่อภาษาอื่นติดมาท้าย (ชื่อไทยสะอาดแล้ว)
- ASEAN FCD เป็นข้อมูลปี 2014 ส่วน Thai FCD ของ INMU เป็นเวอร์ชัน 3 (2568) ที่ใหม่กว่า
  แต่เปิดให้ค้นทีละรายการเท่านั้น ถ้าได้รับอนุญาตจาก INMU ควรอัปเดตด้วยข้อมูลชุดใหม่

## วิธีเพิ่มความรู้

1. คัดลอก `cards/_TEMPLATE.md` เป็นไฟล์ใหม่ ตั้งชื่อไฟล์เป็น slug ภาษาอังกฤษ
2. เขียนเนื้อหาเป็นภาษาไทยด้วยสำนวนตัวเอง ทุกตัวเลขต้องมีที่มาใน `sources`
3. อัปเดตสถานะใน `SOURCES.md`
4. รัน `python -m ingest` จากโฟลเดอร์ `backend/` (embed เฉพาะการ์ดที่เนื้อหาเปลี่ยน)
