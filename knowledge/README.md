# ฐานความรู้ (knowledge base)

## โครงสร้าง

```
knowledge/
├─ cards/          knowledge cards ภาษาไทย 1 ไฟล์ = 1 หัวข้อ (ต้นทางของ RAG)
│  └─ _TEMPLATE.md ไฟล์ที่ขึ้นต้นด้วย "_" จะไม่ถูก ingest
├─ sources/        PDF/เอกสารต้นฉบับ (ไม่ commit ขึ้น git)
├─ SOURCES.md      บรรณานุกรมกลาง + เช็กลิสต์ว่าอ่าน/สรุปอะไรไปแล้ว
└─ foods.csv       ตารางคุณค่าทางโภชนาการอาหารไทย (ต้นทางของ lookup_food)
```

## ⚠️ foods.csv ตอนนี้เป็นค่าตั้งต้นชั่วคราว

ทุกแถวที่คอลัมน์ `source` เป็น `TOVERIFY-INMU` หรือ `TOVERIFY-LABEL`
คือค่าประมาณที่ใส่ไว้เพื่อให้ระบบทำงานได้ระหว่างพัฒนา **ยังไม่ใช่ข้อมูลอ้างอิงจริง**

ก่อนนำไปทดสอบกับผู้ใช้จริงหรือเก็บผลการประเมิน ต้องแทนค่าทุกแถวด้วยข้อมูลจาก
ตารางคุณค่าทางโภชนาการของอาหารไทย (กองโภชนาการ กรมอนามัย) หรือฐานข้อมูล INMU
มหาวิทยาลัยมหิดล แล้วเปลี่ยนคอลัมน์ `source` เป็นชื่อแหล่งจริงพร้อมปีที่อ้างอิง

คอลัมน์ที่บังคับ: `name_th, serving_desc, serving_g, kcal, protein_g, carb_g, fat_g`
คอลัมน์เสริม: `name_en, category, fiber_g, source`

## วิธีเพิ่มความรู้

1. คัดลอก `cards/_TEMPLATE.md` เป็นไฟล์ใหม่ ตั้งชื่อไฟล์เป็น slug ภาษาอังกฤษ
2. เขียนเนื้อหาเป็นภาษาไทยด้วยสำนวนตัวเอง ทุกตัวเลขต้องมีที่มาใน `sources`
3. อัปเดตสถานะใน `SOURCES.md`
4. รัน `python -m ingest` จากโฟลเดอร์ `backend/` (embed เฉพาะการ์ดที่เนื้อหาเปลี่ยน)
