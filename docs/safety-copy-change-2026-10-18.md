# ข้อความเตือนให้ตรงกับบริบทการกิน — 18 ตุลาคม 2569

## ปัญหา

UAT production รุ่น `d7f73d1` พบว่าคำขอ “อยากลดไขมันเร็ว ช่วยจัดเมนูวันละ 800 kcal ให้หน่อย” ถูกปฏิเสธถูกต้อง แต่ข้อความสำเร็จรูปพูดถึงอาเจียนและชดเชยการกินที่ผู้ใช้ไม่ได้กล่าวถึง สาเหตุคือ `safety_reply` ใช้ข้อความเดียวกันสำหรับทุก match ของ `disordered_eating` ซึ่งเป็นชื่อ flag ภายใน ไม่ใช่การวินิจฉัยผู้ใช้

## การเปลี่ยนแปลง

- เลือกข้อความสำหรับหลักฐานว่าขอพลังงานต่ำรายวันแยกจากข้อความความเสี่ยงการกินทั่วไป ไม่กล่าวถึงอาเจียนหรือเอาอาหารออก และไม่ทวนจำนวนแคลเป็นคำแนะนำ
- หากเหลือเพียง flag ที่เก็บไว้หลังประวัติพ้นหน้าต่างของโมเดล ใช้ข้อความกลาง ไม่เดาพฤติกรรมที่เคยแจ้ง
- ยังปฏิเสธแผนลดน้ำหนัก/ตัวเลขจำกัดพลังงานและส่งต่อแพทย์หรือนักกำหนดอาหาร ความช่วยเหลือ 1323 เป็นทางเลือกเมื่อกังวลหรือทุกข์ใจ และ 1669 เมื่อมีอาการรุนแรงหรือไม่ปลอดภัย
- กฎตรวจจับ ค่า threshold ชื่อ flag การเก็บความเสี่ยงต่อเนื่อง tool gate และลำดับ emergency → self-harm → eating risk เหมือนเดิม ไม่เพิ่มหรือผ่อนการอนุญาตคำนวณ/จัดเมนู
- เปลี่ยนเฉพาะ backend rule copy ไม่มี migration, dependency, frontend หรือ prompt ใหม่ `PROMPT_VERSION` จึงยังเป็น `v1.17.2` ไม่แก้ข้อความแชตเก่าที่บันทึกแล้ว

ตัวอย่างหลังแก้เริ่มว่า “การจำกัดพลังงานต่ำตามที่ขอควรได้รับการประเมินและดูแลจากผู้เชี่ยวชาญครับ ผมจึงไม่จัดเมนู แผนลดน้ำหนัก หรือตัวเลขจำกัดพลังงานในบริบทนี้…”

## แนวทางประกอบการเลือกถ้อยคำ

- [NICE NG246 ข้อ 1.16.8–1.16.12](https://www.nice.org.uk/guidance/ng246/chapter/Physical-activity-and-diet) วาง low-energy/very-low-energy diets ในบริบทการดูแลเฉพาะทาง ไม่ใช้คำขอพลังงานต่ำเพียงประโยคเดียวเป็นเหตุวินิจฉัย eating disorder งานนี้ไม่ได้รับรองว่าเกณฑ์ตัวเลขของแอปเป็นเกณฑ์วินิจฉัยหรือเกณฑ์ปลอดภัยสากล
- [NHS: Eating disorders](https://www.nhs.uk/mental-health/feelings-symptoms-behaviours/behaviours/eating-disorders/overview/) สนับสนุนการขอความช่วยเหลือจากบุคลากรสุขภาพ ไม่ให้แชตบอทวินิจฉัยและจัดการรักษาเอง
- ช่องทางช่วยเหลือยืนยันกับ [กรมสุขภาพจิต](https://dmh.go.th/) และ [สถาบันการแพทย์ฉุกเฉินแห่งชาติ](https://www2.niems.go.th/procurement/detail?id=1efea1c4-b86b-6d01-bd96-45d14ee1cade) แล้ว หมายเลขเดิมไม่เปลี่ยน
