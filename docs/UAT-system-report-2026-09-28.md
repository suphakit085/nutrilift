```text
backend/.venv/Scripts/python.exe -m pytest backend/tests -q -p no:cacheprovider
npm test  (ใน frontend/)
backend/.venv/Scripts/python.exe eval/meal_plan_sweep.py --details
```

Backend มี deprecation warning ของ Starlette/httpx 1 รายการ; frontend มี warning เรื่อง package module type การทดสอบทั้งหมดจบด้วย exit code 0 ส่วน console สุดท้ายของเบราว์เซอร์มี 429 และ net::ERR_FAILED ตรงกับเหตุการณ์จำลองที่ตั้งใจทดสอบ

## การล้างข้อมูลและงานที่ยังต้องทำ

ลบบัญชีสังเคราะห์ A/B แล้ว ตรวจจำนวนข้อมูลคงเหลือใน users, profiles, conversations, food_log_entries และ messages ตาม ID เดิมได้ 0 ทุกตาราง ออกจากระบบและตรวจไม่เหลือ token หรือ session storage ของชุดทดสอบ ไม่เก็บรหัสผ่านหรือ JWT ในรายงานและไฟล์หลักฐาน

ก่อนรับมอบควรแก้ D-01 ถึง D-03 แล้วรัน testcase ที่เกี่ยวข้องซ้ำบน deployment ที่แก้จริง ผลนี้ครอบคลุมฟังก์ชันที่ระบุ แต่ยังไม่ได้ทดสอบโหลดพร้อมกันจำนวนมาก การกู้คืนฐานข้อมูลจาก backup, Safari/Firefox หรืออุปกรณ์มือถือจริง และยังไม่ใช่ผลรับรองคำตอบทางโภชนาการจากผู้เชี่ยวชาญหรือผล SUS จากผู้เข้าร่วมจริง
