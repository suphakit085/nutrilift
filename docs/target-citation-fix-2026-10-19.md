# Q1: ที่มาของสูตรและอ้างอิงคำตอบเป้าหมายส่วนบุคคล

กรณีต้นเหตุจาก UAT: “จากโปรไฟล์ตอนนี้ ฉันควรกินพลังงานและโปรตีนวันละเท่าไร ใช้สูตรอะไร ขอแหล่งอ้างอิงด้วย” ได้ตัวเลข 2587 kcal และโปรตีน 126 กรัมถูกต้อง แต่ไม่มีเอกสารให้ตรวจ และไม่อธิบายว่าโปรตีนมาจาก 70 × 1.8

## สาเหตุและสิ่งที่เปลี่ยน

1. `clean_answer` เคยลบ citation ทั้งย่อหน้าที่มีคำว่า “พลังงานเป้าหมาย” ทำให้อ้างอิงงานวิจัยในบรรทัดถัดไปหายด้วย ทำซ้ำด้วยโค้ด main `1789118` ได้จริง แก้เป็นพิจารณาข้อความก่อน citation แต่ละชุด ตามบรรทัด/ประโยค คงการลบอ้างอิงปลอมบนผลคำนวณ กติกาโครงการ และคำแนะนำใช้แอป ไม่ลบเพียงเพราะงานวิจัยกล่าวถึงคำว่าพลังงานเป้าหมาย
2. คำถามขอวิธีคำนวณ/ที่มาของเป้าส่วนบุคคลใช้ผลจากเครื่องคำนวณจริงแสดงตรง ไม่รอให้โมเดลเลือกว่าจะบอกอ้างอิงหรือไม่ เพิ่ม `calculation_details` ใน payload เพื่อส่งตัวตั้งก่อนปัดเศษและค่าสัมประสิทธิ์ที่ใช้จริง ไม่เปลี่ยนสูตรหรือเป้าหมายเดิม
3. คำตอบแสดงสมการ BMR ตัวคูณกิจกรรม วิธีเลือกค่ากลางพลังงานและโปรตีน พร้อมแยกว่าอะไรเป็นวิธีที่โครงการเลือก และอะไรเป็นหลักฐานทั่วไป ตัวอย่าง 126 กรัมแสดง 70 × 1.8 ชัดเจน เป้าชั่วคราวในห้องและคำเตือนจากเครื่องคำนวณยังมีผล ไม่แก้โปรไฟล์ถาวร
4. ตรวจเบราว์เซอร์พบว่าหน้าคำตอบเดิมไม่รองรับ Markdown links จึงเพิ่มการแสดงลิงก์ HTTP(S) และลิงก์ภายในที่กดได้ ลิงก์ภายนอกเปิดแท็บใหม่โดยตัด opener; HTML และ URL ที่ไม่รองรับคงเป็นข้อความ ไม่เรียก HTML จากโมเดล คง bold/code/citation S และการแสดงข้อความระหว่าง streaming
5. เมื่อลิงก์อยู่ในคำตอบโดยไม่มี citation cards แถบแหล่งอ้างอิงบอกให้อ่านลิงก์ในคำตอบ แทนแสดงว่าไม่มีแหล่งอ้างอิง

เส้นทางอธิบายเป้าหมายส่ง `rule:target_explanation`, provider tokens 0 และ `retrieval_status=not_required` ลิงก์เป็นเอกสารต้นทางของวิธีคำนวณ ไม่ปลอมเป็น S จาก retrieval และไม่ปะปนกับคะแนน groundedness ของ RAG คำถามงานวิจัยทั่วไป/การเปรียบเทียบ/เมนูยังใช้เส้นทางเดิม ขอบเขตโรค ผู้เยาว์ ตั้งครรภ์ และพฤติกรรมกินเสี่ยงทำงานก่อนเส้นทางนี้

## แหล่งที่ตรวจ

- [Mifflin และคณะ 1990 — PubMed](https://pubmed.ncbi.nlm.nih.gov/2305711/): บทคัดย่อระบุสมการแยกชาย/หญิงที่เครื่องคำนวณใช้อยู่ รองรับวิธีประมาณพลังงานขณะพัก ไม่ได้ยืนยันตัวคูณกิจกรรมหรือเป้าพลังงานเฉพาะผู้ใช้
- [ISSN: Jäger และคณะ 2017](https://link.springer.com/article/10.1186/s12970-017-0177-8): ช่วงโปรตีนรวม 1.4–2.0 กรัม/กิโลกรัม/วันสำหรับผู้มีสุขภาพดีที่ออกกำลังกายส่วนใหญ่ ไม่ได้กำหนดค่ากลาง 1.8 หรือรับรองช่วงที่โครงการเลือกทุกเป้าหมาย
- กรณีกรอกเปอร์เซ็นต์ไขมัน ระบบยังใช้ Katch-McArdle เดิม แต่ยังไม่มีลิงก์ต้นฉบับที่ตรวจสมการนี้โดยตรงได้ จึงแสดงสูตรที่ระบบใช้และช่องว่างหลักฐานตรงๆ ไม่ยก Mifflin มาเป็นอ้างอิงแทนสมการคนละสูตร การเติมเอกสารต้นฉบับของ Katch เป็นงานหลักฐานที่ยังค้าง
