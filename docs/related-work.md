# งานที่เกี่ยวข้อง: แชตบอทโภชนาการ และแหล่งข้อมูลที่ใช้

ใช้เป็นต้นฉบับของบทที่ 2 (ทบทวนวรรณกรรม) — สืบค้นเมื่อ 31 ส.ค. 2569

เครื่องหมาย ✅ = เปิดอ่านต้นฉบับแล้ว · 🔎 = ได้จากผลการค้นหา ยังไม่ได้เปิดตรวจเอง

## 1. ปัญหาที่โปรเจกนี้ตอบ: แชตบอททั่วไปตอบโภชนาการการกีฬาได้ไม่แม่นพอ

✅ **Sports nutrition knowledge of LLM chatbots** — *PLOS One*, 2025
https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0325982

งานชิ้นนี้คือ **หลักฐานสนับสนุนที่ตรงที่สุดว่าทำไมโปรเจกนี้ควรมีอยู่** ควรอ้างในบทที่ 1 และ 2

- ทดสอบแชตบอท 6 ตัวจาก 3 ค่าย: ChatGPT-4o mini / 4o, Gemini 1.5 Flash / Pro,
  Claude 3.5 Sonnet / Claude Pro
- การทดลองที่ 1: ให้ตอบคำถามโภชนาการการฝึกและการแข่ง แล้วผู้เชี่ยวชาญ 2 คน
  (ประสบการณ์ 15+ ปี) ให้คะแนน โดยใช้ **ACSM 2016, ISSN review 2018 และ IAAF 2019
  เป็นเอกสารเกณฑ์ตัดสิน** — ซึ่งเป็นเอกสารชุดเดียวกับที่ฐานความรู้ของโปรเจกนี้ใช้
- การทดลองที่ 2: ข้อสอบปรนัย 111 ข้อ แนวข้อสอบ Certified Specialist in Sports Dietetics

**ผลลัพธ์ที่ต้องยกมาอ้าง**

| ประเด็น | ผล |
|---|---|
| ความถูกต้อง (การทดลองที่ 1) | **31% – 74%** แล้วแต่โมเดล (Claude Pro ต่ำสุด, Gemini 1.5 Pro สูงสุด) |
| ความครบถ้วน | ChatGPT-4o สูงสุด (ปานกลางถึงสูง) ตัวอื่นต่ำถึงปานกลาง |
| คุณภาพการอ้างอิงหลักฐาน | **ต่ำ** เมื่อใช้ prompt สั้น ๆ · ดีขึ้นเมื่อ prompt ละเอียด |
| จุดอ่อนที่ระบุชัด | energy availability, การได้รับน้ำ (hydration), อาหารเสริม |

**ข้อสรุปของผู้เขียน:** *"Until significant advancements are made, athletes and coaches should
consult registered dietitians for tailored nutrition advice."*

**และข้อเสนอแนะของผู้เขียนคือแนวทางเดียวกับโปรเจกนี้พอดี:** ให้ฝึก/เสริม LLM ด้วย
*"evidence-based sports nutrition guidelines combined with retrieval-augmented generation (RAG)"*
โดยมีผู้เชี่ยวชาญด้านโภชนาการร่วมตรวจสอบ

> เขียนในเล่มได้ว่า: โปรเจกนี้ทำสิ่งที่งานวิจัยชิ้นนี้เสนอไว้ตรง ๆ คือเอา position stands
> มาเป็นฐานความรู้แบบ RAG แทนที่จะพึ่งความรู้ในตัวโมเดล และเพิ่มการประเมินโดยผู้เชี่ยวชาญ

## 2. งานภาษาไทยที่ใกล้เคียงที่สุด

🔎 **ThaiNutriChat: development of a Thai large language model-based chatbot for health food
services** — Luangaphirom T, Jocknoi L, Wunchum C, Chokerungreang K, Siriborvornratanakul T.
*Multimedia Systems.* 2024;30(5):298.
https://link.springer.com/article/10.1007/s00530-024-01495-6
⚠️ ไม่ open access — ต้องใช้สิทธิ์ห้องสมุด

| ประเด็น | ThaiNutriChat | โปรเจกนี้ (NutriLift) |
|---|---|---|
| กลุ่มเป้าหมาย | ผู้ป่วย/กลุ่มเสี่ยง NCDs | ผู้ฝึกเวทเทรนนิ่ง |
| แหล่งข้อมูล | วารสารวิชาการจากองค์กรสุขภาพไทย + ชุด Q&A 1,000 คู่ | position stands สากล + Thai DRI + Thai FCD |
| การเตรียมข้อมูล | OCR ด้วย Tesseract + augment จาก TyDi QA | เขียน knowledge cards เองจากแหล่งปฐมภูมิ |
| เทคนิค | RAG · LoRA fine-tuning · และแบบผสมทั้งสอง | RAG อย่างเดียว + function calling |
| การคำนวณตัวเลข | ไม่ได้ระบุว่าแยกออกจาก LLM | **แยกเป็นฟังก์ชัน Python ที่มี unit test** |

**จุดต่างที่ใช้อ้างความใหม่ของโปรเจกได้ 2 ข้อ**
1. ยังไม่พบงานภาษาไทยที่ทำ **โภชนาการสำหรับเวทเทรนนิ่งโดยเฉพาะ** (ที่พบเน้น NCDs หรือ
   การนับแคลอรี่จากรูปอาหาร)
2. ยังไม่พบงานที่ **แยกการคำนวณ TDEE/มาโครออกจาก LLM ด้วย function calling**
   แล้วรายงานว่าตัวเลขตรวจสอบได้ 100% — งานส่วนใหญ่ปล่อยให้โมเดลคำนวณเอง

🔎 **Thai food recognition and nutritious calculation on LINE chatbot with deep learning**
*Rattanakosin Journal of Science and Technology*
https://ph02.tci-thaijo.org/index.php/RJST/article/view/246266
งานไทยที่ใช้ LINE + deep learning จำแนกรูปอาหารแล้วคำนวณโภชนาการ — คนละโจทย์ (คนละ input
modality) แต่ใช้อ้างเป็นบริบทงานไทยด้านนี้ได้ และเป็นเหตุผลสนับสนุนว่าทำไมโปรเจกนี้
ตัด "วิเคราะห์รูปอาหาร" ออกจากขอบเขต

## 3. แหล่งข้อมูลของแชตบอทโภชนาการที่ใช้ RAG (นานาชาติ)

### ✅ DietGlance — arXiv 2502.01317
https://arxiv.org/html/2502.01317v1

**ฐานความรู้ประกอบด้วย**
- ฐานข้อมูลสารอาหารที่รัฐรับรอง
- รายงานการบริโภคและข้อแนะนำจากรัฐบาลและ WHO
- หน้าเว็บของหน่วยงานรัฐที่มีสูตรอาหารและบทความโภชนาการ
- เนื้อหาจากองค์กรที่น่าเชื่อถือสูง เช่น NIH
- บทความวิจัยที่ผ่าน peer review

**วิธีทำ:** ตัดด้วย LangChain `RecursiveCharacterTextSplitter` ได้ **16,438 หน้าเอกสาร**
เก็บใน Faiss vector database ด้วย OpenAI embeddings

**ผลการเปรียบเทียบ RAG vs ไม่ใช้ RAG** (ใช้เทียบกับผลของโปรเจกนี้ได้โดยตรง)
- ความคลาดเคลื่อนของการวิเคราะห์สารอาหาร (MAPE) ต่ำกว่าเมื่อใช้ RAG โดยเฉพาะน้ำตาล
  แคลเซียม และโซเดียม ซึ่งเป็นสารอาหารที่มัก "ซ่อน" อยู่ในซอสและเครื่องปรุง
- คะแนนความถูกต้องจากผู้เชี่ยวชาญ **4.78 (RAG) vs 4.62 (ไม่ใช้ RAG)** — ต่างกันอย่างมีนัยสำคัญ
- ข้อสังเกตที่น่าสนใจ: ผู้เชี่ยวชาญบอกว่าคำตอบแบบ RAG **บางครั้งซับซ้อนเกินไปจนนำไปใช้จริงยากขึ้น**

> เทียบกับผลของโปรเจกนี้: correctness 4.93 vs 4.20 และ groundedness 4.60 vs 3.27
> ทิศทางตรงกัน และช่องว่างของเรากว้างกว่า (เพราะฐานความรู้เราแคบและตรงโจทย์กว่ามาก)
> ข้อสังเกตเรื่อง "ซับซ้อนเกินไป" เป็นสิ่งที่ควรถามในแบบสอบถาม SUS ด้วย

### 🔎 HealthGenie — arXiv 2504.14594
https://arxiv.org/pdf/2504.14594
ใช้ RAG ร่วมกับ knowledge graph โดยสร้าง "professional corpus" เป็นฐานความรู้
เพื่อให้ LLM ตีความและใช้แนวปฏิบัติด้านอาหารที่เป็นทางการได้ดีขึ้น
⚠️ ผมดึง PDF มาแล้วแต่อ่านไม่ออก (เป็น binary) — ต้องเปิดอ่านเอง

### 🔎 LLM-RAG for Healthy Eating Index-Informed Food Recommendations — arXiv 2605.15213
ให้เหตุผลว่า RAG ทำให้คำแนะนำอิงหลักฐานที่ดึงมาจริง แทนที่จะอิงข้อความทั่วไปจากอินเทอร์เน็ต

## 4. สรุปว่า "ข้อมูลของแชตบอทแนวนี้มาจากไหน"

จากที่สืบค้นมา แหล่งข้อมูลแบ่งได้ 4 กลุ่ม และงานที่ดีมักผสมหลายกลุ่ม

| กลุ่ม | ตัวอย่าง | โปรเจกนี้ใช้ไหม |
|---|---|---|
| ฐานข้อมูลองค์ประกอบอาหารของรัฐ/สถาบัน | USDA FoodData, **Thai FCD (INMU)** | ✅ `foods.csv` |
| ข้อแนะนำสารอาหารระดับชาติ | WHO, **Thai DRI 2563** | ⬜ ยังไม่ได้ใส่ (ควรเพิ่ม) |
| Position stands / consensus statements | **ISSN, ACSM/AND/DC, IAAF** | ✅ แกนหลักของ knowledge cards |
| งานวิจัยเฉพาะเรื่องที่ผ่าน peer review | meta-analysis, narrative review | ✅ |

**ข้อสังเกตที่นำไปเขียนในเล่มได้**

1. **ไม่มีงานไหนที่พบใช้ข้อมูล "ที่แต่งเอง"** — ทุกงานอ้างฐานข้อมูลของรัฐหรือวารสารที่ผ่าน
   peer review ซึ่งย้ำว่า `foods.csv` ของเราต้องแทนด้วยข้อมูล INMU จริงก่อนเก็บผลประเมิน
2. **ขนาดฐานความรู้ต่างกันมาก** — DietGlance ใช้ 16,438 หน้า ส่วนเราตั้งเป้า 60+ การ์ด
   นี่ไม่ใช่จุดอ่อนถ้าอธิบายว่าขอบเขตเราแคบและลึกกว่า (โภชนาการเวทเทรนนิ่งอย่างเดียว)
   แต่ต้องระบุเป็นข้อจำกัดให้ชัด
3. **การประเมินมาตรฐานของสาขานี้** คือให้ผู้เชี่ยวชาญให้คะแนนแบบ Likert เทียบ RAG กับ no-RAG
   ซึ่งตรงกับที่โปรเจกนี้ออกแบบไว้แล้ว
4. **ไม่พบงานไหนที่แยกการคำนวณออกจาก LLM อย่างชัดเจน** — เป็นช่องว่างที่โปรเจกนี้เติมได้
