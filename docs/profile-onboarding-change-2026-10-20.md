# พาไปกรอกโปรไฟล์หลังสมัครหรือเข้าสู่ระบบ — 20 ตุลาคม 2569

ปัญหา: สมัครด้วย OTP และตั้งรหัสผ่านแล้วเข้าสู่หน้าแชตทันที ทำให้ผู้ใช้ใหม่ไม่ทราบว่าควรกรอกโปรไฟล์ก่อนรับคำแนะนำเฉพาะบุคคล

## พฤติกรรมหลังแก้

- สมัครบัญชีใหม่สำเร็จ: ไป `/profile` พร้อมข้อความแนะนำ
- เข้าสู่ระบบ: ตรวจอีเมลและความยินยอมก่อน แล้วตรวจ `/profile` จากเซิร์ฟเวอร์ มีข้อมูลไป `/chat`; ได้ 404 ไป `/profile`
- หลังให้ความยินยอม: ใช้หลักเลือกหน้าปลายทางเดียวกับการเข้าสู่ระบบ
- บันทึกโปรไฟล์ครั้งแรกสำเร็จ: ไป `/chat`
- แก้โปรไฟล์เดิม: คงอยู่หน้าโปรไฟล์เพื่อดูเป้าหมายที่คำนวณใหม่
- บันทึกไม่สำเร็จ: คงฟอร์มและแสดงข้อผิดพลาด
- ตรวจโปรไฟล์แล้วเกิด 401/403/500 หรือปัญหาเครือข่าย: ไม่ตีความว่าไม่มีโปรไฟล์ ให้จัดการสถานะสิทธิ์เดิมหรือแสดงข้อผิดพลาด

เป็นการปรับหน้าปลายทางหลังยืนยันบัญชี/เข้าสู่ระบบ ไม่ได้เพิ่มข้อบังคับใหม่ว่าห้ามอ่านแชตทั่วไปโดยไม่มีโปรไฟล์ ไม่เปลี่ยนสูตรคำนวณ API ฐานข้อมูล หรือเล่มวิทยานิพนธ์
